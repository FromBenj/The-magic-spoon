### What it is
___
**The Magic Spoon** is an SPA dedicated to helping any chef in the making to get the perfect weight or volume of 
a recipe ingredient, with a unique tablespoon.

### Technological challenges
___
- **Express**
- **Mustache** Javascript template
- **lowdb** JSON database
- **dotenv** for environment variables
- **CSV Parse** to transform CSV into Arrays/Objects
- **Swiper** touch slider
- **Vite**
- **dotLottie Web Component** to import animations

### Familiar Technologies
___
- Vanilla JS
- GSAP
- SCSS
- Bootstrap
- Font Awesome

### Test the app
___
- Clone the GitHub Repo (branch **Master**)
```
  git clone https://github.com/FromBenj/The-magic-spoon.git
```
- Launch the server 
```
  npm run backend
```
The **database file will be created automatically** in the backend/data folder.

- Launch Vite
```
  npm run dev
```
- Get a coffee and test it
